# ⚡ 전기 탐구실 (중2 과학 Ⅶ. 전기와 자기)

| 주소 | 대상 | 내용 |
|---|---|---|
| `…/electric/` | 학생 | 반·번호·이름·PIN 입장 → 1~8차시 탐구활동, 형성평가, 제출, 호기심 회로 게시판 |
| `…/electric/teacher.html` | 교사 | 수업 진행용 발표 화면 (비밀번호 `star2026`, 별 탐구실과 같음) · 아래 막대의 [👀 학생 화면]으로 학생 화면 미리보기 |
| `…/electric/?preview=1` | 교사 | 학생 화면 미리보기 (로그인 없이 보기, 제출·게시 안 됨) |

> 별 탐구실(`star` 저장소)과 주소·구글 시트는 **따로** 움직임.
> 학생 로그인 **PIN만 별 탐구실과 공유**(별 탐구실 ‘학생 명부’를 읽기만 함) · **닉네임은 이 단원에서 새로 정함**.

## 차시 구성
1. 마찰 전기 (236~237쪽) · 2. 정전기 유도와 검전기 (238~241쪽) · 3. 전류와 전압 (242~243쪽) · 4. 옴의 법칙 (244~247쪽)
5. 저항의 직렬·병렬 (248~249쪽) · 6. 전기 에너지와 소비 전력 (250~253쪽) · 7. 코일 주위의 자기장 (257~259쪽) · 8. 코일이 받는 힘과 전동기 (260~263쪽)

각 차시: 생각 열기(예측) → 탐구하기(가상 실험 + 직접 기록) → 발견 정리(내 생각을 써야 [정리 확인]이 열림) → 형성평가 5문항 → 제출

## 처음 한 번만 설정하기

### 1. 구글 시트 연결 (학생 제출물·게시판 저장소)
1. 구글 드라이브에서 **새 스프레드시트** 만들기 (예: `전기 탐구실 기록`) — 별 탐구실 시트와 다른 파일
2. 메뉴 **[확장 프로그램] → [Apps Script]**
3. 기본 코드를 지우고 `apps-script/Code.gs` 내용을 붙여 넣기
4. 코드 위쪽 `const STAR_SHEET = '';` 따옴표 안에 **별 탐구실 구글 시트 주소**를 붙여 넣고 💾 저장
   (별 탐구실과 같은 PIN으로 로그인하게 됨 · 비워 두면 전기 탐구실에서 PIN을 새로 정함)
5. 오른쪽 위 **[배포] → [새 배포]** → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
6. **[배포]** → 권한 승인 (별 탐구실 시트를 읽는 권한도 함께 승인) (‘확인되지 않은 앱’ 경고가 나오면 [고급] → [이동])
7. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사
8. `index.html`에서 `const API_URL = '';` 줄을 찾아 따옴표 안에 붙여 넣고 저장 (Claude에게 URL을 알려 주면 대신 바꿔 줌)

### 2. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save** → 1~2분 뒤 주소가 생김

## 시트에 쌓이는 내용
- **학생 명부**: 반·번호·이름·닉네임(이 단원용)·PIN
  - 별 탐구실에 등록된 학생은 PIN 칸에 `(별 탐구실 PIN)`으로 표시되고, 별 탐구실과 같은 PIN으로 로그인
  - PIN을 잊으면 **별 탐구실 시트**의 PIN 칸을 지우기 → 학생이 별 탐구실에서 새 PIN을 정하면 두 곳 모두 적용
  - 별 탐구실에 없는 학생(전학생 등)은 전기 탐구실에서 PIN을 새로 정함 (잊으면 이 시트의 PIN 칸 지우기)
- **1차시 탐구 ~ 8차시 탐구**: 학생 한 명당 한 줄 (예측, 관찰 표, 발견 정리, 형성평가 첫 점수·통과 여부·서술형). 다시 제출하면 최신 내용으로 바뀌고 ‘제출 횟수’가 늘어남
- **질문 / 답변**: 게시판 글. 실명은 시트에만 기록되고 게시판에는 닉네임으로 표시
  - 부적절한 글: **숨김** 체크 → 게시판에서 사라짐
  - 좋은 글: **좋은 글** 체크 → +5점
  - 선생님 답변: ‘답변’ 시트 새 줄에 **질문 ID**를 복사해 넣고, **반** 칸에 `교사`, **답변** 칸에 내용 입력
- 시트 메뉴 **[⚡ 전기 탐구실]** → 반·번호 순 정렬 / 학생 점수 새로 계산

## 수정하면?
GitHub 저장소의 파일이 바뀌면 1~2분 안에 같은 주소에 자동 반영됨.
Apps Script 코드를 바꾼 경우: [배포] → [배포 관리] → 연필 → 버전 [새 버전] → [배포] (주소 그대로 유지)

## 참고
- 교사 화면 비밀번호는 가벼운 잠금 장치임 (수업 화면에는 학생 개인정보가 없음)
- 학생 작성 내용은 기기에 자동 저장되고, 제출하면 다른 기기에서 로그인해도 불러옴
- 시뮬레이션 값은 이해를 돕기 위해 단순화함 (전기 기구 소비 전력·냉장고 효율 등급은 예시 값, 니크롬선은 교과서 결과 210 mA·590 mA @6 V 기준)

## 🚫 패널티 (기간 동안 로그인 막기)
- 시트의 **패널티** 탭: 한 줄 = 한 명 (반 · 번호(비워도 됨) · 이름 · 시작일 · 종료일 · 사유 · 상태)
- 시작일~종료일(종료일 포함) 동안 로그인·제출·게시판 글쓰기가 막히고, 학생 화면에 패널티 기간과 다시 들어올 수 있는 날짜가 보임
- 종료일 다음 날 자동으로 풀림 · 일찍 풀려면 그 줄을 지우거나 종료일을 어제로 바꾸기
- 패널티가 끝난 뒤에도 학생 화면 이름 옆에 “⚠ 패널티 기록 N회 · 날짜 (사유)”가 계속 보임 (시트에서 그 줄을 지우면 사라짐)
- **학생 명부**의 '패널티' 칸에 기간이 표시됨 (시트 메뉴 → [패널티 시트 정리]로 새로 표시)
- 전기 탐구실은 별 탐구실 시트의 패널티 탭도 함께 확인함 (별 탐구실에만 적어도 두 곳 모두 막힘)

## 👀 수업 중 이탈 감지
- 교사 화면 아래 막대 **[👀 이탈 감지]** (또는 `…/watch.html`) → 교사용 페이지 비밀번호 → 반 고르기 → **[▶ 이 반 감지 시작]**
  - 학생 이름이 보이니 **화면 공유 중이면 휴대폰에서 열기**
- 켠 동안 그 반 학생 화면 아래에 “👀 수업 중 · 다른 앱이나 탭으로 나가면 선생님께 기록돼요”가 보임
- 학생이 화면을 벗어나면(다른 앱·다른 탭·홈 화면·화면 꺼짐) 🔴 이탈 중 + 나가 있는 시간, 이탈 횟수·총 시간이 보임 (8초마다 갱신)
- 무엇을 했는지는 알 수 없음 · 정한 시간(45/50/90분)이 지나면 자동으로 꺼짐
- 전체 기록: 시트 **이탈 기록** 탭 (나간 시각 · 돌아온 시각 · 이탈 시간(초) · 보던 화면)
